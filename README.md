# StF Model Renamer
a small app made in Godot to swap Sonic the Fighters model files (.stfmdl, .stf.mat, .stfuvs) between the naming conventions of coatlessali's HoneyPatcher and bekzii's Blender scripts. (assuming that the models in Blender are still named after their model ID before export!)

Drag and drop files into the window to swap their naming conventions. That's all there is to it! This should make it substantially easier to release model mods using HoneyPatcher's model injector rather than as a rom patch (which is better for mod compatibility!) especially when replacing animated models like South Island's palm trees.
